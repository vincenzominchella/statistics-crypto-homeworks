Ex. 1 • 3-Line Algorithm

Mathematical Derivation from Knuth's Mean:

Knuth Running Mean Recurrence (1962)
x̄k = x̄k-1 + (xk − x̄k-1) / k
Welford Running Sum of Squares Recurrence (1962)
M2,k = M2,k-1 + (xk − x̄k-1)(xk − x̄k)
Sample Variance: sk² = M2,k / (k − 1)  •  Population Variance: σk² = M2,k / k

// The core logic requires exactly 3 lines:
const delta = x - mean;
mean += delta / k;
M2 += delta * (x - mean);

Empirical variance of x̄n and sn² across m hackers evaluated at horizons n ∈ [5, 10, 20, 50, 100, 200, 500, 1000]. Both collapse to zero hyperbolically as 1/n.

Analytical Takeaways & Inferential Implications:

1. Variability of the Sampling Mean Var(x̄n)

By the Bienaymé formula for IID variables, Var(x̄n) = σ² / n. The standard error decreases as 1/√n. As n → ∞, the sampling mean becomes an almost deterministic point estimate μ (Law of Large Numbers).

2. Variability of the Sample Variance Var(sn²)

The sampling variance of sn² follows Var(sn²) = (1/n)[μ4 − ((n−3)/(n−1))σ⁴]. Because μ4 (the 4th central moment) is finite for any bounded score in [0, 10], Var(sn²) → 0 as O(1/n).

3. Operational Inferential Utility

In real security audits, defenders observe only one hacker's trajectory. Unbiasedness guarantees no systematic under/over-estimation, while increasing sample depth n tightens confidence intervals: x̄n ± tα/2 · sn / √n.

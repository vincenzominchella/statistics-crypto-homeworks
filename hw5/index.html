Liouville’s Theorem & The Need for Numerical Algorithms

Differential Algebra
Why cannot Φ(z) be expressed in terms of elementary functions?

By Liouville's Theorem on Integration in Finite Terms (1835), an antiderivative of the form ∫ e−x² dx is elementary if and only if there exists a rational function R(x) satisfying:

R'(x) − 2x R(x) = 1

If R(x) = P(x)/Q(x), polynomial degree comparison shows that the left-hand side has degree deg(P) + 1 ≥ 1, making it algebraically impossible to match the constant 1. Hence, e−x² has no elementary antiderivative.

The introduction of the error function erf(x) defines an exact analytical representation Φ(z) = 0.5 • [1 + erf(z/√2)], but because erf(x) is transcendental, numerical methods (quadrature, Chebyshev approximations, or series) are strictly required for practical computation.
